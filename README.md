# H-Core AI ⚡🛡️

Núcleo personal de Inteligencia Artificial ejecutado 100% de forma local en Kali Linux. Diseñado y firmado por **Hernán Vásquez Ocaña** para asistencia técnica en ciberseguridad, análisis de redes, scripting y administración de sistemas.

## Instalación y Uso
1. Clonar el repositorio: `git clone https://github.com/hernanvasqueztlc-cloud/h-core-ai.git`
2. Ejecutar el núcleo: `python3 hcore.py`
